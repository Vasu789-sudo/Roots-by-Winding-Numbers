Every polynomial has a root.

This page proves it by counting how many times a loop winds around zero. Watch the curve: its winding number can only change when it sweeps across the origin, and that sweep is a root.

Abstract

One integer, two radii, one contradiction

Let p be a polynomial of degree n ≥ 1 with complex coefficients. For every radius r ≥ 0 the map t ↦ p(reit) traces a closed loop in the plane. If p had no zero, none of these loops would touch 0, and each would have a well defined integer winding number around 0.

Wr := W( t ↦ p(reit) )  ∈  ℤThe integer attached to the loop of radius r. It is the number of times the loop goes counterclockwise around the origin.

The proof needs three facts. First, the winding number does not change under a perturbation smaller than the distance to the origin, so r ↦ Wr is a continuous integer valued function on an interval, hence constant. Second, at r = 0 the loop is the single point p(0), so W0 = 0. Third, for r large, p(z) is so close to zn that Wr = n. Then 0 = n ≥ 1, which is absurd.

History

Four centuries of attempts

The statement was believed long before it was proved. The dates and credits below are the ones commonly given in the history of mathematics; where sources disagree about a date or an attribution, treat the entry as approximate.

The winding number argument used on this page is a modern, algebraic-topology style rendering of the geometric idea behind several of the early proofs. Versions of it appear in many textbooks, and pinning down who wrote it first is difficult, so no single credit is claimed here.

Preliminaries

Five tools, nothing more

The proof uses only the following standard facts. Each is proved in a first course on analysis or complex numbers, and none depends on the theorem being proved.

1. The exponential

For w = x + iy, ew = ex(cos y + i sin y). It is continuous, ea+b = eaeb, and ew = 1 exactly when w ∈ 2πiℤ.

2. A logarithm on the right half-plane

On H = {Re u > 0} define Log u = ln|u| + i arctan(Im u / Re u). It is continuous, eLog u = u, and Log 1 = 0. The disc |u − 1| < 1 lies inside H because Re u ≥ 1 − |u − 1| > 0.

3. Compactness

A continuous real function on a closed bounded set such as [0, 1] × [0, 2π] is bounded, attains its minimum, and is uniformly continuous. Polynomials are continuous.

4. Integer valued functions

A continuous function from an interval to ℤ is constant. This is the intermediate value theorem: a continuous function that takes two integer values would take every value between them.

5. Triangle inequalities

|a + b| ≤ |a| + |b| and |a + b| ≥ |a| − |b|. They control how far a polynomial strays from its leading term.

What the exponential does

The picture below is the reason a loop in ℂ∖{0} has a well defined number of turns: eφ wraps the φ-plane around the origin infinitely often, and a continuous choice of φ keeps count.

The statement

The Fundamental Theorem of Algebra

Theorem

Let n ≥ 1 and let p(z) = anzn + … + a1z + a0 with every ak ∈ ℂ and an ≠ 0. Then:

  1. (1)Existence. There is z0 ∈ ℂ with p(z0) = 0. proved in Parts 1 to 8
  2. (2)Factorisation. There are z1, …, zn ∈ ℂ, not necessarily distinct, with p(z) = an(z − z1)⋯(z − zn). Corollary 1
  3. (3)Uniqueness and count. The list z1, …, zn is unique up to order, so p has exactly n roots counted with multiplicity. Corollary 2
  4. (4)Real coefficients. If all ak are real, then p is a product of real linear factors and real quadratic factors with negative discriminant, and non-real roots come in conjugate pairs of equal multiplicity. Corollary 4
  5. (5)Counting form. If R > 0 and p has no zero on |z| = R, then W( t ↦ p(Reit) ) equals the number of zeros of p in |z| < R, with multiplicity. In particular every zero satisfies |z| < 1 + Σk<n |ak/an|. Corollaries 7 and 8
∀ p ∈ ℂ[z], deg p = n ≥ 1  ⟹  ∃ z0 ∈ ℂ : p(z0) = 0The core statement, part (1). Everything else on this page follows from it together with the winding number tools.

Hypotheses, and why each one is there

  • Degree at least 1. A nonzero constant such as 5 has no root.
  • Coefficients in ℂ. Over ℝ the statement fails: x2 + 1 has no real root. Over ℂ the coefficients may be real, rational or genuinely complex.
  • Leading coefficient nonzero. This is what makes the degree n and what makes p behave like zn far from the origin.
  • Multiplicity. The count of exactly n roots is with multiplicity, so (z − 1)2 has the root 1 counted twice.
Intuition

A person, a dog, and a tree

A person walks once around a tree along a circle. A dog on a leash follows. If the leash is always shorter than the person's distance to the tree, the dog can never reach the tree, so the dog must also go around the tree exactly as many times as the person. This is the whole engine of the proof.

| f(t) − g(t) | < | g(t) | for all t  ⟹  W(f) = W(g)Leash length on the left, distance from the person to the tree in the middle. Made precise in Part 4.

Now apply it to p. Take the loop of radius r in the z-plane and send it through p. When r is tiny the image is a tiny loop near p(0), which does not surround the origin, so it winds 0 times. When r is huge the image looks like zn, so it winds n times. As r grows the image deforms continuously. A loop can only change its winding number by being dragged across the origin, and being dragged across the origin means p(reit) = 0 for some t. That is a root.

The rest of the page turns this picture into a proof. Parts 2 and 3 say exactly what “number of turns” means, Part 4 is the leash, Part 5 is the continuous deformation, and Parts 6 and 7 compute the two ends.

1 Part 1 of 8

Setup and strategy

p(z) = zn + an−1zn−1 + … + a1z + a0,   n ≥ 1The normalised polynomial. Its zero set is the same as that of the original.
  1. Divide the given polynomial by its leading coefficient an ≠ 0. This does not change the zeros, so we may assume p is monic. Put A = |a0| + |a1| + … + |an−1|.
  2. For each radius r ≥ 0 define the path
    γr(t) = p(reit),   0 ≤ t ≤ 2πThe image under p of the circle of radius r.
    Since p is continuous, the map (r, t) ↦ γr(t) is continuous. Since e0 = e2πi, each path is closed: γr(0) = γr(2π).
  3. Suppose, for contradiction, that p(z) ≠ 0 for every z ∈ ℂ. Then γr(t) ≠ 0 for every r and t, so every γr is a closed path in ℂ∖{0}. In particular a0 = p(0) ≠ 0.
  4. Plan. Parts 2 and 3 define an integer W(γr) for such paths. Parts 4 and 5 show it cannot depend on r. Part 6 computes it at r = 0, Part 7 computes it at a large radius, and Part 8 observes that the two answers differ.
2 Part 2 of 8

A continuous logarithm along a path

Lemma 2

Let f : [a, b] → ℂ∖{0} be continuous and let ew0 = f(a). Then there is exactly one continuous φ : [a, b] → ℂ with φ(a) = w0 and

eφ(t) = f(t)   for all t ∈ [a, b]φ is called a lift of f through the exponential.
  1. Local logarithm. If |u − 1| < 1 then Re u > 0, so Log u from the preliminaries is defined, continuous, satisfies eLog u = u, and Log 1 = 0.
  2. Uniform control. The set f([a, b]) is compact and misses 0, so m := min |f| > 0. By uniform continuity there is δ > 0 such that |s − t| ≤ δ implies |f(s) − f(t)| < m.
  3. Ratios stay in the disc. For |s − t| ≤ δ,
    | f(s)f(t) − 1 | = |f(s) − f(t)||f(t)| < mm ≤ 1So the ratio f(s)/f(t) lies in the disc around 1 where Log is defined.
  4. Build the lift piece by piece. Choose a = t0 < t1 < … < tN = b with each gap at most δ. Put φ(t0) = w0 and, on [tj, tj+1],
    φ(t) = φ(tj) + Log f(t)f(tj)Defined successively for j = 0, 1, …, N − 1.
  5. It is a continuous lift. If eφ(tj) = f(tj) then on the next piece eφ(t) = f(tj) · f(t)/f(tj) = f(t), and induction starts from ew0 = f(a). At the break point tj+1 the next piece starts at the value the previous piece ends with, because Log 1 = 0 gives φ(tj+1) from either formula. Each piece is continuous, so φ is continuous.
  6. Uniqueness. If φ and ψ are two continuous lifts with the same starting value, then eφ−ψ = 1, so (φ − ψ)/(2πi) is a continuous integer valued function that is 0 at a. By tool 4 it is constant, hence 0.

The same argument shows that two lifts with arbitrary starting values differ by a constant in 2πiℤ.

3 Part 3 of 8

The winding number

A closed path avoiding 0 is a continuous f : [0, 2π] → ℂ∖{0} with f(0) = f(2π).

W(f) = φ(2π) − φ(0)2πiwhere φ is any continuous lift of f from Part 2.
  1. It is an integer. eφ(2π) = f(2π) = f(0) = eφ(0), so φ(2π) − φ(0) ∈ 2πiℤ and W(f) ∈ ℤ.
  2. It is well defined. Another lift differs from φ by a constant (Part 2, uniqueness), which cancels in the difference.
  3. Meaning. Im φ is a continuous choice of argument of f, and Re φ = ln|f| returns to its starting value. So 2πW(f) is the total change of the argument: the number of counterclockwise turns around 0.
  4. Property (W1). For an integer n and a constant c ≠ 0, the path ceint has the lift ln c + int (taking a logarithm ln c of c), so W = n.
    W( c eint ) = n
  5. Property (W2). A constant path c ≠ 0 has constant lift, so W = 0.
  6. Property (W3). If φ lifts f and ψ lifts g, then φ + ψ lifts fg, because eφ+ψ = fg. Hence
    W(fg) = W(f) + W(g)
  7. Property (W4). If f takes values in the disc |u − 1| < 1, then Log ∘ f is a continuous lift. Since f(0) = f(2π), Log f(2π) = Log f(0), so W(f) = 0.
4 Part 4 of 8

The leash lemma

Lemma 4

Let f, g : [0, 2π] → ℂ be continuous with f(0) = f(2π) and g(0) = g(2π), and suppose

|f(t) − g(t)| < |g(t)|   for every t ∈ [0, 2π]The leash is shorter than the distance from the person g(t) to the tree at 0.

Then f and g are closed paths avoiding 0 and W(f) = W(g).

  1. Neither path hits 0. The inequality forces |g(t)| > 0. If f(t) = 0 we would get |g(t)| < |g(t)|, which is false. So both are closed paths in ℂ∖{0}.
  2. Form the ratio. Let h(t) = f(t)/g(t). It is continuous and h(0) = h(2π).
  3. The ratio stays near 1. Dividing the hypothesis by |g(t)|,
    |h(t) − 1| = |f(t) − g(t)||g(t)| < 1
  4. The ratio does not wind. By (W4), W(h) = 0.
  5. Conclude with multiplicativity. Since f = hg, property (W3) gives
    W(f) = W(h) + W(g) = 0 + W(g)

The strict inequality matters at every single t. Pitfall 2 below shows what goes wrong when the leash is allowed to be too long.

5 Part 5 of 8

Homotopy invariance: the winding number is constant in the radius

Lemma 5

Let H : [0, 1] × [0, 2π] → ℂ∖{0} be continuous with H(s, 0) = H(s, 2π) for each s. Then s ↦ W(H(s, ·)) is constant.

  1. A positive gap. The domain is compact and H never vanishes, so m := min |H| > 0.
  2. Small steps are leashes. H is uniformly continuous, so there is δ > 0 such that |s − s′| < δ gives
    |H(s, t) − H(s′, t)| < m ≤ |H(s′, t)|   for all t
  3. Apply Lemma 4. With f = H(s, ·) and g = H(s′, ·), the hypothesis of Lemma 4 holds, so W(H(s, ·)) = W(H(s′, ·)).
  4. Chain the steps. Pick N with 1/N < δ and compare s = j/N with (j+1)/N for j = 0, …, N−1. All the windings are equal, so W(H(0, ·)) = W(H(1, ·)), and the same argument works between any two values of s.
  5. Use it for p. Fix any R > 0 and put H(s, t) = p(sReit). Under the standing assumption that p has no zero, H is continuous, never 0, and closed in t. Therefore
    W(γ0) = W(γR)The winding number at radius 0 equals the winding number at every radius R.
6 Part 6 of 8

The small circle: winding number 0

γ0(t) = p(0) = a0 ≠ 0  ⟹  W(γ0) = 0The loop of radius 0 is a single point that is not the origin.
  1. At r = 0 we have 0·eit = 0 for every t, so γ0 is the constant path a0.
  2. By Part 1, a0 ≠ 0 under our assumption. By (W2), W(γ0) = 0.
  3. Small positive radii agree. The same conclusion holds for small r > 0 directly. For |z| = r,
    |p(z) − a0| ≤ B(r) := Σk=1n |ak| rkwith an = 1 in the monic case.
    B is continuous and increasing with B(0) = 0, so there is r0 > 0 with B(r) < |a0| for r < r0. For those radii Lemma 4 applies with f = γr and g ≡ a0, giving W(γr) = 0. The loop never leaves the disc of radius |a0| around a0, and that disc excludes 0.
7 Part 7 of 8

The big circle: winding number n

R = 1 + A,   A = Σk=0n−1 |ak|  ⟹  W(γR) = nRadius 1 plus the sum of the moduli of the lower coefficients.
  1. Compare with the leading term. Let |z| = R. Since R ≥ 1 we have Rk ≤ Rn−1 for k ≤ n−1, so
    |p(z) − zn| = | Σk<n akzk | ≤ Σk<n |ak| Rk ≤ A Rn−1
  2. The choice of R makes it a leash. Because A < 1 + A = R,
    A Rn−1 < Rn = |zn|So |p(z) − zn| < |zn| everywhere on the circle of radius R.
  3. Apply Lemma 4. Take f = γR and g(t) = (Reit)n = Rneint. Both are closed paths and the leash condition holds for every t. Hence W(γR) = W(g).
  4. Compute W(g). By (W1) with c = Rn, W(g) = n. So W(γR) = n.

The same estimate shows that no root has modulus ≥ R: for |z| ≥ 1 + A, |p(z)| ≥ |z|n−1(|z| − A) ≥ 1.

8 Part 8 of 8

The contradiction

0 = W(γ0) = W(γR) = n ≥ 1The first equality is Part 6, the second is Part 5, the third is Part 7. The conclusion is absurd.
  1. Assume p has no zero in ℂ. Then every γr is a closed path avoiding 0 (Part 1), so every W(γr) is a defined integer (Part 3).
  2. Part 6 gives W(γ0) = 0.
  3. Part 5, applied with R = 1 + A and the homotopy H(s, t) = p(sReit), gives W(γ0) = W(γR).
  4. Part 7 gives W(γR) = n.
  5. Combining, 0 = n. But n ≥ 1 by hypothesis. This contradiction shows that the assumption was false: p has at least one zero in ℂ. ∎

Where each hypothesis was used

  • n ≥ 1: to contradict W = 0 in the last line. For a constant the two ends agree and nothing is proved, as it must be.
  • an ≠ 0: to normalise to a monic polynomial, which makes the leading term zn dominate on the big circle.
  • No zeros (the assumption): to make every γr avoid 0, so that the winding numbers exist, Lemma 5 applies, and a₀ ≠ 0.
  • Coefficients in ℂ: to be able to rotate in a plane, so that circles, exponentials and the leash estimate exist.
Corollaries

What the root buys you

Once one root exists, everything else is algebra, plus one more use of the leash lemma. Below, parts (2) to (5) of the theorem and four consequences are proved from part (1).

Corollary 1. Factorisation

p = an(z − z1)⋯(z − zn).

Proof. Induct on n. For n = 1, a1z + a0 = a1(z + a0/a1). For n ≥ 2, part (1) gives a root z1. Polynomial division gives p(z) = (z − z1)q(z) + c with c constant. Putting z = z1 gives c = p(z1) = 0. Now q has degree n − 1 and leading coefficient an, and the induction hypothesis factors it. ∎

Corollary 2. Exactly n roots with multiplicity

The list z1, …, zn is unique up to order.

Proof. Suppose an∏(z − zj) = an∏(z − wj). Evaluating at z1 makes the left side 0, so some factor z1 − wj vanishes. Cancel the common factor (a product of nonzero polynomials is nonzero) and repeat on the remaining n − 1 factors. ∎ The multiplicity of a root is how many times it appears in the list.

Corollary 3. ℂ is algebraically closed

Every irreducible polynomial over ℂ has degree 1, and every finite extension field of ℂ equals ℂ.

Proof. An irreducible q of degree ≥ 2 has a root z0 by part (1), so (z − z0) divides it by Corollary 1, a contradiction. If L ⊇ ℂ is a finite extension and α ∈ L, the minimal polynomial of α over ℂ is irreducible, hence linear, hence α ∈ ℂ. ∎

Corollary 4. Real polynomials

A real polynomial is a product of real linear factors and real quadratics with negative discriminant.

Proof. For real coefficients, p(z) = p(z), so non-real roots come in pairs w, w. Conjugating the factorisation and using Corollary 2 shows the two have equal multiplicity. Then (z − w)(z − w) = z2 − 2 Re(w)z + |w|2, which is real with discriminant −4(Im w)2 < 0. ∎

Corollary 5. Odd degree has a real root

A real polynomial of odd degree has at least one real root.

Proof. By Corollary 4 the non-real roots, counted with multiplicity, pair up, so their number is even. The total is n, which is odd, so at least one root is real. ∎

Corollary 6. Eigenvalues

Every complex n × n matrix M with n ≥ 1 has an eigenvalue.

Proof. det(λI − M) is a monic polynomial of degree n in λ. It has a root λ0, so λ0I − M is singular and has a nonzero kernel vector. ∎ Repeating on a complement gives triangularisation (Schur form).

Corollary 7. A bound on all roots

Every root satisfies |z| < 1 + Σk<n |ak/an|.

Proof. Normalise to monic and put R = 1 + A. For |z| ≥ R, |p(z)| ≥ |z|n − A|z|n−1 = |z|n−1(|z| − A) ≥ 1 > 0. ∎

Corollary 8. Counting zeros in a disc

This is part (5) of the theorem. If p has no zero on |z| = R, then W(γR) equals the number of zeros of p in |z| < R.

Proof. Write γR(t) = an∏(Reit − zj) and use (W2), (W3). For a factor with |zj| < R, the leash lemma with g = Reit gives winding 1, since |zj| < R = |g|. For |zj| > R, the leash lemma with the constant g ≡ −zj gives winding 0, since the distance moved is R < |zj|. Summing the windings counts the roots inside. ∎

W( γR ) = #{ j : |zj| < R }Corollary 8: the winding number counts the roots inside the circle, with multiplicity. Part 8's staircase is this formula plotted against R.

Pitfalls

Three ways the argument breaks

1. A radius that hits a root

At r equal to the modulus of a root, the loop passes through 0 and the winding number is not defined. The proof never evaluates W there, and the numerical diagrams show a warning near such radii. The staircase has a step at that radius, not a value.

2. Unsigned crossings are not winding

A tempting shortcut is to count how often the loop crosses the negative real axis. That count is wrong unless each crossing carries a sign: upward +1, downward −1. The signed total equals W, while the unsigned count does not. The lift in Part 2 keeps the signs automatically.

3. The field matters

The theorem is about complex roots. x2 + 1 has no real root, yet its two roots ±i exist. A polynomial with real coefficients can lose its real roots as a coefficient changes, and the roots then leave the real line in a conjugate pair rather than disappear.

More small traps

  • Writing the proof for a nonconstant polynomial but forgetting that Lemma 5 needs the loop to avoid 0 for every radius at once, not just the two ends.
  • Using the principal argument as if it were continuous. It jumps by 2π, and only the lift of Part 2 is a continuous argument.
  • Applying Lemma 4 with a non-strict inequality. If |f − g| ≤ |g| the leash can reach the tree, and f may vanish.
  • Forgetting that W is only defined for closed paths. A path that does not return to its start has a fractional total argument change.

Exercise 1

Compute W(γr) for p(z) = z3 − 1 with r = 1/2 and with r = 2, and justify each.

HintFor r = 1/2 use |p + 1| = r3 < 1. For r = 2 compare with z3.
SolutionAt r = 1/2, |p(z) − (−1)| = 1/8 < 1 = |−1|, so W = W(−1) = 0. At r = 2, |p − z3| = 1 < 8 = |z3|, so W = W(8e3it) = 3.

Exercise 2

Show that z5 + 3z + 1 has exactly one zero in |z| < 1.

HintCompare with 3z on |z| = 1 using Lemma 4, then use Corollary 8.
SolutionOn |z| = 1, |p(z) − 3z| = |z5 + 1| ≤ 2 < 3 = |3z|. So W(γ1) = W(3eit) = 1, and by Corollary 8 there is one zero inside. Numerically it is −0.33199.

Exercise 3

Show that all roots of z4 + z + 1 satisfy |z| < 2, which is better than the bound 3 from Corollary 7.

HintUse the radius 2 directly in the leash lemma.
SolutionOn |z| = 2, |z + 1| ≤ 3 < 16 = |z4|. So W(γ2) = 4 and all four roots lie in |z| < 2. In fact the largest modulus is about 1.1838.

Exercise 4

For a closed path f avoiding 0, prove W(1/f) = −W(f) and W(f) = −W(f).

HintIf φ lifts f, what lifts 1/f? What lifts the conjugate?
Solutione−φ = 1/f, so −φ is a lift and the difference at the endpoints changes sign. For the conjugate, eφ = eφ, and φ(2π) − φ(0) is the conjugate of φ(2π) − φ(0) = 2πiW, which is −2πiW.

Exercise 5

Show that a closed path lying inside an open disc that does not contain 0 has winding number 0.

HintLet the disc have centre c and radius ρ < |c|, and use Lemma 4 with the constant path c.
SolutionIf |f(t) − c| < ρ and the disc misses 0, then ρ ≤ |c|, so |f − c| < |c|. Lemma 4 gives W(f) = W(c) = 0.

Exercise 6

Prove: if p has no zero in the closed disc |z| ≤ R, then W(γR) = 0.

HintThis is Parts 5 and 6 with the assumption restricted to a disc.
SolutionThe homotopy H(s, t) = p(sReit) is nonvanishing because |sReit| ≤ R. By Lemma 5, W(γR) = W(γ0) = 0.

Exercise 7

A real quartic has no real root. Show it is a product of two real quadratics.

HintPair the four roots into conjugate pairs.
SolutionThe four roots are non-real, so they form two conjugate pairs w, w and v, v. Each pair gives a real quadratic (z − w)(z − w), and the quartic is their product times its leading coefficient.

Exercise 8

Let w be a root of multiplicity m and the only root on |z| = |w|. Show that W(γr) jumps by m as r crosses |w|.

HintUse Corollary 8 for radii just below and just above |w|.
SolutionFor r slightly below |w| the number of roots inside is k, and for r slightly above it is k + m, since only w (counted m times) enters. Corollary 8 turns these counts into the winding numbers.
Generalisations

Where the same idea goes

The argument principle

If f is differentiable and φ lifts it, then eφ = f gives φ′ = f′/f. Integrating over [0, 2π] and substituting f(t) = p(Reit), with dz = iReitdt, turns the winding number into a contour integral. This is the bridge to complex analysis.

Rouché's theorem

If f and g are holomorphic near a closed disc and |f − g| < |g| on its boundary circle, then f and g have the same number of zeros inside. The proof is Lemma 4 together with the argument principle. Exercise 2 is a polynomial instance.

Degree theory

Replacing the loop by its direction f/|f| gives a map from the circle to the circle, and W is its degree. Homotopy invariance (Lemma 5) is the fact that degree is a homotopy invariant, which is behind the statement that the fundamental group of the circle is ℤ. A similar winding argument is a standard route to the two-dimensional Brouwer fixed point theorem.

Other proofs

Common alternatives are the minimum modulus argument in the d'Alembert–Argand tradition, a proof by Liouville's theorem, and a Galois theory proof that uses only that real odd degree polynomials have real roots. Each uses a different corner of mathematics, which is part of why the theorem is a favourite.

Where it stops

The statement is special to ℂ. Over the quaternions the equation x2 + 1 = 0 has infinitely many solutions, and a root existence theorem for a restricted class of quaternionic polynomials is commonly credited to Niven in the 1940s and to Eilenberg and Niven shortly after.

Conclusion

What to carry away

Takeaways

  • A closed path in ℂ∖{0} has an integer winding number, defined through a continuous logarithm.
  • If |f − g| < |g| at every point, f and g wind the same number of times (the leash lemma).
  • So the winding number of p(reit) is constant in r unless a loop touches 0, and touching 0 is a root.
  • At r = 0 the winding number is 0, at r = 1 + Σ|ak| it is n. Hence a root exists.
  • The same bookkeeping counts roots in any disc.
